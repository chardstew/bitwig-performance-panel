01

Install and connect

  1. Drag PerformancePanel.bwextension onto an open Bitwig Studio window.
  2. In Settings → Controllers, add CHXRD → Performance Panel.
  3. Open 127.0.0.1:32146 in Chrome. The status rail should show BITWIG CONNECTED.

If drag installation is unavailable, copy the file to Bitwig Studio's Extensions directory for your operating system, restart Bitwig, and continue from step 2.

Recommended

Choose Chrome ⋮ → Cast, save, and share → Install page as app. This removes Chrome's toolbars and creates a standalone Performance Panel shortcut for quick launch.

02

Remote Controls

  1. Follow a device. DEV shows the selected track, device, and Remote Controls page. Use the arrows to navigate from the panel; changes work both ways with Bitwig.
  2. Open Project Remotes. PROJ switches the same eight controls to Bitwig's project-wide Remote Controls. They remain available regardless of track or device selection.
  3. Keep device pages in view. In DEV, choose ＋ Add Remote Page to pin the current page below while you navigate elsewhere.

Bitwig remains the source for track hierarchy, names, colors, and Remote Control assignments. Existing MIDI and controller mappings carry straight through, with no second mapping layer to recreate or maintain. When the active Bitwig project changes, Performance Panel follows it and loads that project's pinned pages and layout. The Transport Bar above the Navigator provides project transport and status, with ＋ Add Remote Page and Settings at the right.

03

Pinned Remote Pages

Pin up to 32 Device Remote Controls pages in the banks below the Navigator. These are synchronized views, not copies: each keeps its Bitwig track and device context while the main selection changes. Project Remotes stay available through PROJ and do not need to be pinned.

04

Mixer

＋ Track adds the selected track; ＋ All fills the mixer from the enabled track types. Each strip provides pan, level, metering, mute, solo, and record arm. Use × to remove a strip from the panel.

Settings can show or hide the mixer, place it at the top, middle, bottom, or alongside the pinned banks, and set it to Full, Half, or Quarter width. Narrow widths scroll horizontally.

05

Settings and hotkeys

Use Settings to arrange sections, choose bank density and mixer width, control track colors and visibility, and edit the panel name. The layout is stored with the Bitwig project.

The Track Types group controls which Group, FX, and Master tracks appear in the Navigator and Mixer ＋ All; it does not remove content already added.

Edit Hotkeys assigns optional shortcuts for transport, panel navigation, switching Device and Project Remotes, adding pages, and showing or hiding panel sections.

06

Connection

Open Performance Panel from its installed app shortcut or at 127.0.0.1:32146. The Bitwig extension serves both the interface and its local bridge; no separate server, account, or internet connection is required.

If the panel is offline, confirm the controller is active and restart Bitwig after installation. Duplicate controller entries or a port conflict are reported in Bitwig's controller log.

07

How it works

Performance Panel is one Bitwig controller extension with a browser interface bundled inside it. The extension reads the active project through Bitwig's public API and serves the interface and current state over local HTTP at 127.0.0.1:32146. Browser actions are queued back to the extension and applied inside Bitwig.

The connection stays on this computer and does not process audio. No separate server, cloud service, account, or internet connection is involved.

08

Current limits

Touch and TouchOSC

Controls accept local touchscreen input. A dedicated touch layout, TouchOSC adapter, and secure network bridge are future work; this release runs on the Bitwig computer only.

Modulators

Device modulators are not available because Bitwig's public API does not yet expose complete browsing and control data. Macro, Macro-4, Button, Buttons, LFO, ADSR, and Ramp are the clearest first candidates; graphical and routed modulators will require more API data.

Contributing

Focused bug reports, Bitwig API findings, and tested implementations are welcome. Future support should use real project data through the public API rather than simulated controls.

09

Example Panel Setups

Waiting for a session

Before a Bitwig project is available, the panel stays empty rather than showing placeholder data. It populates automatically when a project becomes available.

Standard

Navigator shown, mixer hidden, and four pinned pages in Mid view (4×2).

Simple (no mixer)

Navigator hidden, mixer hidden, and four pinned pages in Large view (8×1).

Simple + mixer

Navigator hidden, full-width mixer above, and two pinned pages in Large view (8×1).

Dense (no mixer)

Navigator shown, mixer hidden, and 14 pinned pages in Small view (4×2). The panel scrolls vertically.

Dense + small mixer

Navigator shown, quarter-width mixer alongside 14 pinned pages, and Small view (4×2). The panel scrolls vertically.

Complex + mixer

Navigator hidden, half-width mixer alongside 14 pinned pages, and Small view (4×2). The panel scrolls vertically.

Settings

Display options, Navigator position, included track types, pinned-page view, mixer layout, panel labels, and hotkeys.
