## Commands

Commands are POST requests with URL query parameters. The HTTP thread validates
and queues them; Bitwig's controller thread executes them.

### Navigation and Remote Controls

```text
POST /v1/command?action=set-remote&page=0&index=0&value=0.5
POST /v1/command?action=previous-page
POST /v1/command?action=next-page
POST /v1/command?action=previous-track
POST /v1/command?action=next-track
POST /v1/command?action=previous-device
POST /v1/command?action=next-device
POST /v1/command?action=add-bank
POST /v1/command?action=add-bank&bank=3
POST /v1/command?action=release-bank&bank=3
POST /v1/command?action=set-bank-remote&bank=3&page=0&index=0&value=0.5
```

### Settings

```text
POST /v1/command?action=set-include-groups&value=1
POST /v1/command?action=set-include-effect-tracks&value=1
POST /v1/command?action=set-include-master-track&value=1
POST /v1/command?action=set-bank-view&value=0
POST /v1/command?action=set-use-track-color&value=1
POST /v1/command?action=set-show-transport-bar&value=1
POST /v1/command?action=set-show-remote-controls&value=1
POST /v1/command?action=set-remote-controls-position&value=0
POST /v1/command?action=set-show-mixer&value=1
POST /v1/command?action=set-exclusive-solo&value=0
POST /v1/command?action=set-mixer-width&value=0
POST /v1/command?action=set-mixer-position&value=0
POST /v1/command?action=set-section-order&text=mixer%2Cbank%3A0%2Cbank%3A1
POST /v1/command?action=set-panel-title&text=Performance%20Panel
POST /v1/command?action=set-panel-subtitle&text=BITWIG%20PERFORMANCE%20SURFACE
```

- `set-bank-view`: `0` Large, `1` Mid, `2` Small.
- `set-remote-controls-position`: `0` Top, `1` Bottom.
- `set-mixer-width`: `0` Full, `1` Half, `2` Quarter.
- `set-mixer-position`: `0` Top, `1` Middle, `2` Bottom, `3` With Banks.

### Mixer

```text
POST /v1/command?action=add-mixer-track
POST /v1/command?action=add-mixer-all
POST /v1/command?action=release-mixer-track&index=0
POST /v1/command?action=set-mixer-volume&index=0&value=0.75
POST /v1/command?action=set-mixer-pan&index=0&value=0.5
POST /v1/command?action=set-mixer-mute&index=0&value=1
POST /v1/command?action=set-mixer-solo&index=0&value=1
POST /v1/command?action=set-mixer-arm&index=0&value=1
```

### Transport

```text
POST /v1/command?action=transport-play
POST /v1/command?action=transport-stop
POST /v1/command?action=transport-record
POST /v1/command?action=transport-loop
POST /v1/command?action=transport-metronome
POST /v1/command?action=set-tempo&value=120
POST /v1/command?action=undo
POST /v1/command?action=redo
```

Normalized input values are clamped. Index bounds are enforced by the extension.
Unknown actions are ignored and reported in Bitwig's controller log.
