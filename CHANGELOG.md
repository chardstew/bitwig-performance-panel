# Changelog

## 0.1.0-alpha.8

- Added a compact Device / Project source switch to the Remote Control Navigator.
- Added project-wide Project Remotes using Bitwig's native project data and mappings.
- Kept pinned pages device-specific and protected them from Project-mode add actions.

## 0.1.0-alpha.7

- Stabilized Remote Control button feedback during bridge polling.
- Added Bitwig-native binary and stepped parameter handling.

## 0.1.0-alpha.6

First public alpha.

- Project-aware Remote Control Navigator with track, device, and page navigation.
- Up to 32 pinned Remote Controls pages with Large, Mid, and Small views.
- Optional 32-track mixer with flexible placement and width.
- Transport, project-local layout settings, editable hotkeys, and fixed status rail.
- Loopback-only bridge served by the Bitwig extension; no companion process.
- Bundled user guide, gallery, contributor documentation, CI, and MIT license.

Known limits are documented in the User Guide and [README](README.md).
